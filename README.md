# 五料産業株式会社 - コーポレートサイト制作

## 📋 プロジェクト概要

群馬県を拠点とする総合建設業者「五料産業株式会社」のコーポレートサイトを、クライアントとのヒアリングから実装まで一貫して制作しました。Figmaで作成されたデザインを忠実に再現し、2つのデザイン案を実装。モダンなUI/UXとレスポンシブデザインを採用し、企業の信頼性と技術力を表現するサイトを構築しました。

## 🎯 制作プロセス

### 1. ヒアリング・要件定義
- クライアントとの打ち合わせを通じて、企業の理念や強みをヒアリング
- ターゲットユーザー（地域住民、企業、求職者）のニーズを分析
- 競合サイトの調査と差別化ポイントの明確化

### 2. デザイン設計
- Figmaで2つのデザイン案を制作
  - **デザイン1（index.html）**: 信頼感と落ち着きを重視したクラシカルなデザイン
  - **デザイン2（index4.html）**: モダンで洗練された印象を与えるデザイン
- カラースキーム、タイポグラフィ、レイアウトの検討
- ユーザビリティを考慮した情報設計

### 3. 実装
- HTML5/CSS3/JavaScriptによるコーディング
- レスポンシブデザインの実装
- インタラクティブな要素の追加
- パフォーマンス最適化

## 🛠️ 使用技術

### フロントエンド
- **HTML5**: セマンティックマークアップ、アクセシビリティ対応
- **CSS3**: 
  - Flexbox / Grid レイアウト
  - CSS Variables（カスタムプロパティ）による保守性向上
  - CSS Animations / Transitions
  - メディアクエリによるレスポンシブデザイン
- **JavaScript（Vanilla）**: 
  - フレームワーク不使用の軽量実装
  - Intersection Observer API（スクロールアニメーション）
  - RequestAnimationFrame（パフォーマンス最適化）
  - イベント駆動型アーキテクチャ

### 外部リソース
- **Google Fonts**: Inter, Noto Serif JP, Cormorant Infant
- **Google Maps API**: 地図埋め込み

## 🎨 デザインのポイント

### カラースキーム
- **プライマリカラー**: `#E70012`（赤） - 企業の活力と信頼性を表現
- **テキストカラー**: `#0D0D0D`（黒） - 可読性を重視
- **背景**: `#FFFFFF`（白） - クリーンで明るい印象

### タイポグラフィ
- **見出し**: Noto Serif JP / Cormorant Infant - 和の品格と信頼感
- **本文**: Inter - モダンで読みやすいサンセリフ

### UI/UXの特徴
1. **パララックス効果**: スクロールに応じた背景画像の動きで奥行き感を演出
2. **スムーズアニメーション**: フェードイン、スライドインなど自然な動き
3. **インタラクティブなスライダー**: ヒーロー画像、施工事例、お客様の声など
4. **固定CTAバー**: 常時表示される問い合わせボタンでコンバージョン向上
5. **レスポンシブデザイン**: デスクトップ・タブレット・モバイルに対応

## ⚡ 主な機能

### 1. ヒーロースライダー
- 自動スライド（3秒間隔）
- スムーズなフェードトランジション
- ホバーで一時停止
- パララックス効果との連携

### 2. パララックススクロール
- 背景画像の視差効果
- 速度の段階的制御（slow/medium/fast）
- RequestAnimationFrameによる最適化

### 3. スクロールアニメーション
- Intersection Observer APIによる要素検出
- フェードイン、スライドイン、ズームイン効果
- 遅延アニメーションで順次表示

### 4. フローセクション
- インタラクティブなステップ表示
- 画像とテキストの連動
- 自動スライド機能

### 5. 固定ヘッダー
- スクロール時の背景変化
- ハンバーガーメニュー（モバイル対応）
- スムーズなナビゲーション

### 6. 固定CTAバー（デザイン2）
- 電話番号表示
- 無料お見積もりボタン
- 採用エントリーボタン
- スクロール位置に応じた表示制御

### 7. レスポンシブデザイン
- **デスクトップ**: 1440px以上
- **タブレット**: 768px〜1199px
- **モバイル**: 768px未満

## 🚀 セットアップ・実行方法

```bash

python3 -m http.server 8000

npx http-server
```
